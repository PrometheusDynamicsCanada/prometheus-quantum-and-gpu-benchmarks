# Public Disclosure & Intellectual Property Boundary

This repository archives public empirical quantum hardware benchmarks, logical reference circuits and distributions, hardware job identifiers, and standalone verification scripts published by Prometheus Dynamics Canada.

## Proprietary Hardware-Aware Optimization Boundary
In accordance with Prometheus Dynamics' intellectual property boundary policy across all public repositories:
1. **Proprietary Hardware-Aware Optimization:** Prometheus uses circuit structure and device calibration data to guide compilation and execution. Proprietary optimization, compilation, placement, and execution-control software, internal parameters, and physical qubit coordinate mappings are withheld from this public repository.
2. **Clean Single-Commit Repository Release:** This repository is published from a freshly initialized single-commit Git tree (`0` historical pre-sanitization commits in repository object storage).

## Verifiable Empirical Provenance
All published hardware claims in this repository are independently verifiable from the archived hardware Job IDs / Task ARNs, raw measurement histograms, and standalone verification scripts included in this repository.
